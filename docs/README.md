# Pulsar Dock 产品设计文档

文档集：v0.6 讨论稿｜日期：2026-10-24｜状态：已完成 RuntimeBackend 设计、sbx 基础实测、Dock MCP 网关原型和第一条 Claude-in-sbx 真实竖向链路；完整产品未实现。

> Pulsar Dock 是面向人和 Agent 的桌面安全协作工作台：人在界面里授权和检查成果，Agent 在隔离环境中工作，并通过受控接口创建协作者、交换消息和交付结果。

## 文档怎么分

只设一个 `docs/` 目录，不按部门再套目录。八份正文分别回答八个问题：

2. [功能与交互](02-features.md)：用户和 Agent 分别能做什么、页面和操作规则是什么。
3. [产品与技术架构](03-architecture.md)：组件分工、任务与环境模型、接口契约和关键数据流。
4. [安全与兼容](04-security.md)：保护什么、如何限制权限、凭据放哪里、哪些兼容性必须验证。
5. [三天交付与验收](05-delivery.md)：比赛版做多少、如何实施、用什么证据证明完成。
6. [技术选型与验证门槛](06-technology-selection.md)：具体技术栈、备选取舍、本机条件与采用前必须通过的验证。

阅读顺序：先 01，再 02；讨论实现读 03、04 和 06；安排开发看 05。产品完整形态不等于三天必须全部完成。

## 本稿最重要的五条约束

1. 安全规则由 Dock 和隔离运行时执行，不靠 Agent 的提示词自律。
2. 上游真实凭据不进入 Agent 沙箱；沙箱内受限访问凭证仍是敏感能力，必须限权、限时、可撤销。
3. Agent 可以调用平台，但不能修改平台的安全规则，也不能自批权限。
4. 协作通过消息和明确版本的成果交接，不默认共享可写目录。
5. 兼容范围、隔离等级和恢复能力按实际测试声明；不能以减少安全限制换取“支持”。
